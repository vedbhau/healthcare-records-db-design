# Healthcare Records Database Design

This project implements a relational database system for managing electronic healthcare records. It includes schema design, ER diagram, and sample data for entities such as patients, doctors, medical history, diagnostic tests, prescriptions, and more.

## Features
- Patients and Doctors information
- Medical history tracking
- Appointments and encounter logs
- Diagnostic test records and results
- Prescription and dosage tracking
- Surgery and procedure history

## Tools Used
- MySQL
- MySQL Workbench
- Draw.io (for ER Diagram)

## Setup
1. Clone the repo
2. Import `healthcare_db.sql` into MySQL Workbench
3. Use sample queries to test data retrieval
